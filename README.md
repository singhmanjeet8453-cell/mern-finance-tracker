# FinanceAI - MERN Dashboard

A full-stack Finance Dashboard and AI Expense Tracker web application built for placement interviews.

## Features
- **MERN Stack**: MongoDB, Express.js, React.js (Vite), Node.js
- **Auth**: Secure JWT based Authentication
- **Data Visualization**: Interactive Recharts (Pie & Bar charts)
- **AI Features**: Mock AI spending insights and financial chatbot assistant
- **UI/UX**: Modern Tailwind CSS glassmorphism, dark mode default

## Installation

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```
Note: Make sure MongoDB is running on port 27017 or modify the `.env` file.

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173` to view the application!
